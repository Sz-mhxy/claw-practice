# claw-practice

个人练手仓库。这里用来放我学写代码时的小脚本，不追求专业，先把「写代码 + 用 Git」这件事跑通。

## 第 1 个脚本：游戏新闻归档小工具
`news_archive_tool.py` —— 扫描 `游戏新闻/` 目录，统计简报数量、日期范围、文件大小。

运行：
```
python news_archive_tool.py
```

## 这个仓库用来练什么
- Python 基础（文件、循环、字符串处理）
- Git 基础（init / add / commit / push / pull）
- 把日常小需求变成可复用脚本
